BOOK SHOP - BCS353 EXPERIMENTS 1-7

Project:
A simple Online Bookstore website for the BCS-353 Web Designing Workshop lab.
The header includes the GL Bajaj Institute of Technology & Management name and logo.

Files:
- index.html: homepage using three frames (top, left and right)
- top.html: website heading and navigation links
- left.html: department links
- home.html: welcome page
- login.html: Experiment 2 login form
- catalogue.html: Experiment 3 book catalogue
- cart.html and js/cart.js: Experiment 4 shopping cart
- registration.html: Experiment 5 registration form and HTML5 constraints
- js/validation.js: Experiment 7 JavaScript validation
- css/style.css: simple shared page styling
- images/glbajaj-logo.png: college logo used in the header

How to run:
1. Extract the ZIP file.
2. Open the folder in Visual Studio Code.
3. Open index.html in a browser. You can also use the Live Server extension.
4. Add books from Catalogue, then open Cart to see them.
5. Test the registration form with valid and invalid values.

Notes:
- This is a front-end lab demonstration. Login and registration do not create real accounts.
- No payment gateway or backend is included.
- HTML frames are used because Experiment 1 asks for a three-frame homepage.
